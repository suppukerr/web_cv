# Local Platinum assets

`Platinum*.png` and `Charcoal.woff2` were copied from the Infinite Mac repository,
commit f77ee43c24baa804ee9bd7a6d024f1b34aa6244a. The project's Apache 2.0
license is distributed at `../licenses/infinite-mac.txt`. The adapted CSS is
marked in `src/style.css`.

Infinite Mac's `Appearance.css` credits the Charcoal font to https://os9.ca/.
The font is a third-party font; this note does not assign new font ownership.
Geneva and existing Apple/Finder/Trash SVGs were already part of this portfolio.

`folder.png`, `close.png`, `zoom.png`, `collapse.png`, and `resize.png` were
sampled at 1× from the rendered Mac OS 9.0.4 desktop in Infinite Mac. The folder's
outside white background was removed. These samples derive from the displayed
Mac OS artwork rather than Infinite Mac's React source. The browser screenshot
was compressed; they are not lossless resource-fork exports. Underlying classic
Mac OS artwork belongs to its original owners and is not newly licensed by us.

`document.svg`, `alias.svg`, `disk.svg`, and `computer.svg` are portfolio-specific
pixel-vector adaptations. All are served locally under the configured Vite base.
No source checkout or benchmark website is required to build or run the site.

`startup-reference.png` is the Mac OS 9 startup screenshot supplied by the user.
The splash clips its original logo panel in CSS; the frame, status, and progress
bar are HTML/CSS and remain interactive. Classic Mac OS artwork retains its
original ownership. This asset is served locally with no remote requests.
